Customers pay for a plan with UPI, card or net banking, and the plan is switched on by itself. Without keys, customers see the UPI steps above.

Step by step: where to find the keys (no coding)
  1. Sign in at dashboard.razorpay.com. At the top, switch to Test mode to try everything without real money first. Live mode works after Razorpay has activated your account (KYC).
  2. Open Account & Settings → API Keys (on older screens: Settings → API Keys) and press Generate Key. Copy the Key ID and the Key Secret into the boxes above. The secret is shown only once — if you lose it, generate a new key.
  3. Open Account & Settings → Webhooks and press Add New Webhook.
    Webhook URL: …
    Secret: make up a long password (20 or more letters and numbers) and type the same one into Webhook secret above.
    Active events: tick payment.captured and order.paid (you may also tick payment.failed). Press Create / Save.
  4. Press Save here, then Check keys. It says the keys work when Razorpay accepts them.
  5. Give each plan a price: Plans & defaults → Edit → Price. A plan without a price is not shown to customers.
  6. Try one payment in test mode (Razorpay shows test cards and the test UPI ID on its payment screen). When it works, do steps 2–4 again in Live mode: live keys start with rzp_live_ and need their own webhook.

How it works

  1. Add a source channel (or paste one video).
  2. Most-replayed and most-commented moments become clips.
  3. Credit, original tags/description and keywords are added.
  4. Auto upload sources queue clips straight away; Review first waits for you.
  5. Edit a clip and it re-renders and rejoins the queue by itself.
