How it works

  1. Add a source channel (or paste one video).
  2. Most-replayed and most-commented moments become clips.
  3. Credit, original tags/description and keywords are added.
  4. Auto upload sources queue clips straight away; Review first waits for you.
  5. Edit a clip and it re-renders and rejoins the queue by itself.

Helper PC

Your own computer fetches videos and voices when YouTube blocks the server.

Start automatically (recommended, once): in the project folder double-click worker\install_autostart.bat. The helper then runs hidden whenever your PC is on, restarts itself if it stops, and updates itself when the server gets new code.
Manual start: worker\run_worker.bat. New helpers appear here — press Approve.
